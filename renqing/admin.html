上线三步

1. 把整个 renqing-test 目录推到 GitHub 仓库，Settings → Pages 选 main 分支根目录。
2. 打开 js/config.js，把 siteUrl 改成你的真实网址（海报上的二维码靠它）。
3. 改掉 adminKey，生成密码池覆盖 data/passwords.json，完成。

接入 Supabase（一码一用 + 真实数据）

-- 在 Supabase 的 SQL Editor 里执行 create table rqdw_passwords ( code text primary key, used boolean default false, used_at timestamptz, note text ); create table rqdw_results ( id bigserial primary key, ts timestamptz default now(), total int, rank text, dims jsonb, code text ); alter table rqdw_passwords enable row level security; alter table rqdw_results enable row level security; -- 允许匿名读密码（校验用）、匿名写结果 create policy "read pass" on rqdw_passwords for select using (true); create policy "insert result" on rqdw_results for insert with check (true); create policy "read result" on rqdw_results for select using (true);

执行完把 Project URL 和 anon public key 填进 js/config.js 的 supabase 字段即可。
